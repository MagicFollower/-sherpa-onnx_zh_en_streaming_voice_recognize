# 02 交互规范与状态机

## 1. 交互目标与界面信息层级

本篇定义D1交互建议，落实R03至R08、R13、R17和R20；消息以LASR 1.0为准。
用户确认的是按住入口、一次一气泡和实时优先；颜色、布局尺度及异常处理细节是建议基线。
界面方向是克制的录音工作台：以内容和当前采集状态为核心，不做复杂仪表盘、装饰波形或虚假音量。
建议浅暖灰背景、深墨色正文、单一青绿色采集强调色；错误使用独立文字和图标语义，不只靠颜色。
字体使用随离线包提供且许可明确的中文字体或本地系统中文回退，不请求远程字体；具体字体待包体和授权决定。
录音、处理中、已完成、已取消、失败必须有稳定文字标签；动画仅辅助状态，不替代提示。
首屏只保留连接状态、结果区、按住主按钮和帮助入口，模型详细参数放到本地状态信息中。

### 1.1 PC文字布局示意

```text
页头：本地语音输入             本地连接状态 / 模型状态 / 注销
提示：按住鼠标或空格讲话，松手生成终稿
结果区：时间与状态
        本轮完整草稿持续替换，不追加新卡片
        已完成卡片可复制；清空只影响当前页面
底部操作区：取消本轮     按住讲话     空格快捷键提示
底部说明：音频不保存；当前页面历史不跨端同步
```

### 1.2 手机文字布局示意

```text
顶部：本地语音输入 / 连接状态
中部：单列卡片，当前轮始终可见
      草稿、处理中或错误说明
底部安全区域：取消本轮
              大号按住讲话按钮
              松手结束；切后台会取消
```

结果区可滚动，底部按钮避开系统手势安全区；缩放与横屏时不覆盖终稿。
触摸主按钮建议最小64 CSS像素高度，次级操作最小44 CSS像素命中区，均须真机核验。
录音状态自动跟随当前卡片；用户主动浏览旧卡片时不强行抢回滚动位置，可提示“回到当前轮”。
不将模型宣传语作为状态；“本地运行”只表达路径设计，不能显示未经验证的“完全安全”徽章。

## 2. 两层状态与卡片生命周期

连接状态与单轮状态相互独立，避免把连接已建立误认为模型已经可开始。
连接状态为：未配对、连接中、模型准备中、可开始、忙碌、离线、配置异常。
只有配对有效、WSS已建立、模型可用且没有本地未结束轮次时，主按钮才允许产生开始意图。
服务端仍在start阶段做最终容量仲裁；页面就绪不意味着已经预留识别槽位。

| 单轮状态 | 页面文字 | 进入动作 | 允许退出 |
| --- | --- | --- | --- |
| idle | 按住讲话 | 无采集、无活动UUID | 有效按住进入preparing |
| preparing | 正在准备麦克风 | 分配UUID与本地generation；请求能力和权限 | ready且仍按住后recording；否则取消或失败 |
| recording | 正在聆听 | 开采集门、维护样本和seq | 正常松手进入draining；异常进入cancelling |
| draining | 正在提交尾音 | 关采集门，排空已有采样 | stop已发送进入finalizing；失败则failed |
| finalizing | 正在整理文字 | 不再采集，等待唯一终态 | completed、cancelling或failed |
| cancelling | 已停止，正在取消 | 关门、清本地待发音频，发送cancel | cancelled、已丢弃或failed |
| completed | 已完成或未检测到语音 | 接受唯一final，正文不可再改 | 仅复制、清空；新轮使用新UUID |
| cancelled | 已取消 | 收到cancelled或仅本地准备被撤销 | 新按住才开始新轮 |
| failed | 本轮中断 | 显示具体恢复动作，草稿标为未完成 | 新按住才开始新轮 |

有效按住进入preparing即创建一张卡片；权限失败和取消也只更新这张卡片，不额外增加结果卡片。
每张卡片保存自己的UUID、最高revision、终态及本地丢弃标记，不以当前数组末项猜测结果归属。
partial为本轮完整草稿，直接替换对应正文；相同或更低revision不覆盖。
final可以修正尚未完成的草稿，但一旦终态确认，后续消息不得再静默改写。
内部VAD识别多个segment只扩展同一张卡片；段末不是用户整轮final。
失败草稿默认不可用“复制终稿”按钮复制；若后续支持复制草稿，必须明确标注未完成且另行确认。

## 3. 输入所有权与按住规则

### 3.1 Pointer Events

仅主按钮上的首个有效pointerdown取得本轮所有权，记录pointerId和输入来源pointer。
鼠标仅接收主按钮左键；触摸和笔只允许一个拥有者，其他手指或设备不能抢占和触发第二轮。
尝试设置pointer capture；若无法可靠捕获，停止准备并提示重试，不假定一定能收到抬手。
拥有者在按钮外移动但仍被capture时保持录音，移出不是默认取消手势。
pointerup只处理拥有者；先进入正常结束流程，再主动释放capture。
预期释放产生的lostpointercapture不能反向把draining变为取消。
录音或准备状态发生非预期lostpointercapture、pointercancel时统一cancel。
派生click不再触发录音，避免触屏一次动作启动两次。
仅对录音按钮区域使用抑制滚动或选取的策略，不禁用整页缩放和正常滚动。

### 3.2 空格快捷键

首次非repeat空格keydown可取得keyboard所有权；整个key保持期间只产生一次开始意图。
输入框、文本域、可编辑区域、选择框、菜单及其他交互控件拥有焦点时不截获空格。
IME组合输入期间不接管空格，使用组合状态而非仅检查某个键值。
主录音按钮获得焦点时，空格属于该按钮的显式键盘操作；同时阻止由此产生的重复click路径。
页面普通区域接管空格时才阻止页面滚动；没有取得所有权的键事件保持浏览器默认行为。
对应keyup触发正常stop；repeat keydown、非拥有者keyup和其他按键不会结束当前pointer轮次。
已有pointer所有权时忽略空格录音请求，已有keyboard所有权时忽略主按钮的第二个开始请求。
Escape可取消当前轮次，包括finalizing；它不清空其他已完成卡片。
失焦可能导致keyup永不到达，因此必须走第5节取消兜底，不能只依赖keyup。

### 3.3 重新开始条件

recording、draining、finalizing和cancelling期间禁止新轮；取消未清理时显示“正在释放资源”。
达到60秒上限后自动stop，并提示时长上限；仍按着的同一手指或空格不能自动续开下一轮。
必须先释放原输入，再进行新的按住；禁止把长按repeat当作自动分段录音。
用户可以连续多轮，但每轮使用新UUID；服务端没有重连续传旧轮的功能。

## 4. 权限与启动竞态

preparing同时受本地generation、输入所有权、页面可见性和服务端准备状态约束。
第一次按住可触发getUserMedia及音频上下文恢复；此时采集门保持关闭，不发送音频。
权限界面可能改变页面焦点；若触发失焦，则按安全优先规则撤销本轮，授权后提示重新按住。
授权通过不代表可以开始：必须再次检查原generation仍有效、拥有者仍按住、页面可见、未取消。
任一检查失败即停止迟到取得的媒体轨道、关闭或挂起相应音频资源，不发送start。
只有权限和本地音频管线准备完毕，且仍持有按住意图时，才发送start申请服务端槽位。
收到ready后再次检查generation及输入；合格才打开采集门并展示“正在聆听”。
start已发但用户松手时发送cancel，不等待ready后偷偷录音；迟到ready只能用于清理，不能激活采集。
权限尚未通过就松手属于本地取消，不发送0帧正常终稿；已经ready却尚无样本时松手允许合法0帧stop。

```text
按住 → 请求权限，采集门关闭
松手 → generation作废，卡片已取消
迟到授权 → 停止媒体轨道，不发送start
下一次明确按住 → 新UUID、新generation、新一次准备
```

start至ready上限5秒；用户阅读权限弹窗不计入该网络超时，页面不弹循环重试框。
权限拒绝提示浏览器设置入口，设备缺失提示检查麦克风；两者不能仅显示“网络错误”。
证书或安全上下文不合格应先解释HTTPS问题，不能诱导用户反复授予无效权限。

## 5. 正常结束、取消与异常策略

### 5.1 正常stop

正常pointerup、对应空格keyup和单轮时长达到上限使用stop。
收到结束事件立即关闭新增采集门，通知AudioWorklet以确认的源采样截止点结束本轮。
只排空截止点之前已经采集的样本和重采样器可由其产生的合法尾部，不再额外开启尾窗。
最后不足20ms的有效帧也发送，序号与总样本计数包含它；不能为凑帧发送伪造静音采样。
worklet报告drain完成后，确保全部本轮二进制帧已按序交给WebSocket，再发送stop。
发送stop后继续接收ACK与final，不立即关闭WSS；UI进入finalizing并显示取消入口。
麦克风轨道在排空所需边界确认后释放，不为等final持续占用麦克风。
尾部是否完整由stop和ACK的计数验证，不由最后一次partial是否含有句号判断。

### 5.2 默认cancel

| 事件 | 默认行为 | 页面恢复 |
| --- | --- | --- |
| 点击取消或Escape | cancel并丢弃本轮后续正文 | 提示已取消；重新按住 |
| 页面blur或visibility变为hidden | cancel，不保证后台继续录音 | 返回只显示已取消或中断 |
| 锁屏或浏览器挂起 | 能执行时cancel；否则由断连或心跳回收 | 不自动补发或恢复 |
| pointercancel或异常丢capture | cancel，不当作正常松手 | 提示操作被系统中断 |
| 录音设备消失 | cancel并显示设备错误 | 重新选择设备后再按住 |
| 网络断开 | 本地停止，无法发送时不假装cancel已确认 | 显示中断，重连不重放 |
| 主按钮正常移出但capture仍在 | 继续当前轮，正常抬手stop | 不误判为取消 |

上述异常若发生在draining或finalizing且轮次未终结，也使用cancel；不是继续后台等待后突然展示结果。
已经completed的卡片不因页面失焦而取消或改写。
浏览器被系统直接挂起时不能保证执行回调，因此服务端心跳和有界清理是必要兜底，而非录音持续保证。

## 6. 取消与final竞态

服务端对每个UUID只提交一个逻辑终态：final、cancelled或终结性error。
若cancel先提交，worker迟到结果全部丢弃，不再发final。
若final先提交，随后cancel只重发原final，不制造第二个cancelled终态。
客户端一旦有明确取消意图，即设置本地discarded标记，不能被竞态final重新展示正文。
final先发生而本地已丢弃时，卡片显示“本轮已丢弃，结果在取消前完成”，不谎称服务端取消成功。
终态重发仅帮助完成资源释放与幂等确认，不新增卡片、不再次复制或读屏播报。
断网后旧session结果、旧generation回调或不匹配UUID一律不能污染新轮。
取消后2秒仍未收到终态响应时，关闭该WSS并显示取消确认失败；服务端必须完成回收后才重新接单。
具体缓存时间、旧ID响应和终态规则以05_音频与实时通信协议.md第9节“幂等、乱序、旧ID与终态竞争”为准。

## 7. 文字、反馈与无障碍

| 情况 | 建议提示 | 不应出现的误导 |
| --- | --- | --- |
| 就绪 | 按住讲话，松手结束 | 麦克风正在录音 |
| preparing | 正在准备，请保持按住 | 已开始识别 |
| recording但未有文本 | 正在聆听 | 用伪文本填充实时效果 |
| finalizing | 正在整理，请稍候；可取消 | 必定在两秒内完成 |
| 空轮 | 未检测到语音，请重新按住 | 识别失败或虚构文字 |
| 忙碌 | 电脑正在处理另一轮，请稍后重试 | 无提示排队 |
| 正常一遍结果与增强降级 | 已完成；默认配置关闭标点或精修时为正常一遍结果，不称降级；仅在基础结果完整且本轮已启用的标点或精修步骤失败、超时或超预算时提示对应降级，并附原因 | 将配置关闭误报为降级，或将降级结果冒充完整增强结果 |
| 权限拒绝 | 请在浏览器设置允许麦克风 | 自动无限请求权限 |
| 断网 | 本轮已中断，请恢复连接后重新讲话 | 正在自动续传 |

录音按钮必须具备可聚焦状态和简短可读名称；按住状态语义由实现阶段选择适当ARIA表达，不伪装成长期切换开关。
读屏只播报开始、处理中、终态和错误，不按每次partial逐字打断用户。
草稿变化不改变焦点；复制、取消和清空均可键盘到达，清空不能误触后结束正在录音的其他状态。
清空历史在活动轮次时默认禁用；注销则明确取消活动轮并销毁页面正文。
支持系统减少动画偏好；计时器与录音状态必须在关闭动画时仍清楚可辨。
点按开始、再次点按结束的辅助模式没有用户确认，本阶段仅记录扩展需求，不暗中改变默认按住模式。
